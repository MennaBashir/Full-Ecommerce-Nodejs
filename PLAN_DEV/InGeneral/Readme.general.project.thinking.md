# إزاي تبدأي أي مشروع Backend — 7 خطوات

> اتبعيهم بالترتيب. متكتبيش كود قبل ما تخلّصي خطوة 1 → 5 على ورقة.
> التفاصيل والأمثلة في `Notes.Ingeneral.md`.

---

## 1) اكتبي المشروع في 3 أسطر

- **المشكلة** في جملة واحدة.
- **المستخدمين:** مين؟ (Guest / User / Admin)
- **كل واحد بيعمل إيه:** `بصفتي [مستخدم] عايز [أعمل كذا] عشان [الفايدة]`

---

## 2) قسّمي الـ Features

| Must | Should | Later |
|---|---|---|
| من غيرها مفيش مشروع | مهمة وتتأجل | إضافات |

**اختبار:** الـ Must لوحدها بتشغّل المشروع من الأول للآخر؟ لو لأ ← ناقص حاجة.
ابني الـ Must بس الأول (MVP).

---

## 3) طلّعي الـ Models

الأسماء في كلام خطوة 1 = models. (اللون والحجم = fields مش models).

لكل model حددي: الـ **fields** · مين `required`/`unique` · مين **index** (اللي بتفلتري بيه).

---

## 4) وصّلي الـ Models (العلاقات)

لكل اتنين: مين خاص بمين؟ (1:1 / 1:N / N:M)
وبعدين: أخزّنهم مع بعض (**Embed**) ولا منفصلين (**Reference**)؟

| Embed | Reference |
|---|---|
| قليل + بيتقري مع الأب | كتير + بيتقري لوحده |

> القاعدة الذهبية: صمّمي حسب **اللي الشاشة محتاجة تقراه**، مش شكل الداتا.

---

## 5) ارسمي الـ API

```
GET    /api/v1/things      ← list (+ filter + pagination)
GET    /api/v1/things/:id
POST   /api/v1/things
PATCH  /api/v1/things/:id
DELETE /api/v1/things/:id
```

لكل route اكتبي جنبه: **مين يقدر يستخدمه؟** (public / user / admin)

---

## 6) ابني بالترتيب

```
Setup → Auth → Models المستقلة → Models المعتمدة → العمليات المركبة
```

لكل خطوة: **Model → Route + Controller → Validation → جرّبي (نجاح + غلط) → commit**

> لو feature بتستخدم تانية ← ابني التانية الأول.

---

## 7) قبل ما تقولي خلصت

- [ ] Tests للأجزاء الحساسة (auth، فلوس)
- [ ] Error handler موحد
- [ ] Security: helmet + cors + rate limit
- [ ] README + Deploy

---

## القواعد الثابتة (متكسريهاش)

1. **متثقيش في الـ client:** السعر والمجموع يتحسبوا في الـ backend.
2. **الملكية:** اتأكدي إن الداتا بتاعة اليوزر، مش بس إنه مسجّل دخول.
3. **Snapshot:** انسخي السعر/العنوان وقت الحدث.
4. **Validation** لكل input قبل الـ controller.
5. **Pagination** في أي list.
6. **Transaction** لأي عملية على أكتر من collection.
7. **Soft delete** للداتا المرتبطة بغيرها.
8. **Indexes** على اللي بتبحثي/تفلتري بيه.
9. **الفلوس** أرقام صحيحة (قرش/سنت).
10. **متحطيش** array بيكبر بلا حد جوه document.
