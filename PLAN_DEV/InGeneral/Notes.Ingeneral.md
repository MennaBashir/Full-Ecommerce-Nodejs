
دي خريطة العلاقات بين الـ models. الرموز معناها:

الرمز	المعنى
──<	واحد لـ كتير (One-to-Many). الجهة اللي فيها < هي "الكتير"
──1	واحد لـ واحد (One-to-One)
>──	كتير لـ واحد (من الاتجاه العكسي)
سطر سطر

User ──< Address
اليوزر الواحد عنده كذا عنوان (بيت، شغل، ...). بس العنوان الواحد بتاع يوزر واحد.

User ──1 Cart
اليوزر الواحد عنده كارت واحد بس، والكارت الواحد بتاع يوزر واحد.

User ──< Order
اليوزر الواحد ممكن يعمل أوردرات كتير، بس الأوردر الواحد بتاع يوزر واحد.
//



1. أنواع الفهارس (Indexes):
	• index: true: يقوم بتسريع البحث فقط، ويسمح بتكرار القيم في هذا الحقل.
	• unique: true: يقوم بتسريع البحث ويمنع تكرار القيمة في نفس الحقل (مثل البريد الإلكتروني أو اسم المستخدم)، وهو تلقائياً يعتبر فهرساً.
2. التأثير على الكتابة (Writes): الفهارس تجعل القراءة أسرع، لكنها تبطئ قليلاً عمليات الإضافة (insert) والتعديل (update) لأن MongoDB يحتاج إلى تحديث الفهرس مع كل تغيير.
